# 后期实验说明

> 本文档描述**中期报告（`report_latex/main.tex`）之后**的实验计划与运行方式，供终期报告撰写与答辩复现使用。  
> 中期工作以 **RGB + DeepSeek-chat 端到端** 为主；后期在**相同评估框架**下，更换**本地生成模型**并扩展**多领域公开/自建数据集**，验证中期发现的互锁效应与矫正方法是否可迁移。

## 1. 与中期报告的关系

### 1.1 中期已完成的基线（保持不变的部分）

| 模块 | 中期状态 | 后期是否沿用 |
|------|----------|--------------|
| 噪音注入（比例 / 类型 / 位置） | ✅ | ✅ 完全沿用 |
| 12 种矫正方法 + adaptive | ✅ | ✅ 沿用，按数据集裁剪子集 |
| 指标：Judge + ISR/NAR + NS/NRS/CRR | ✅ | ✅ Judge 仍用 DeepSeek |
| 实验脚本 exp1–exp5 + `_runner` | ✅ | ✅ 沿用 |
| 可视化 `src/visualize.py` | ✅ | ✅ 沿用 + 批量出图 |
| Web Demo（FastAPI + Vue） | ✅ | ✅ 已接入新数据集 registry |

### 1.2 中期核心结论（后期需**跨数据集验证**的假设）

1. **互锁效应**：semantic 噪音下 `confidence`（CoT 证据链）最优；counterfactual 噪音下 `prompt` 更稳，`confidence` 可能低于 naive。  
2. **位置效应**：高强度 counterfactual 下 `interleave` 通常优于 `back`。  
3. **自适应路由**：`adaptive` 在 CF 场景可避开 confidence 崩溃，整体 ≥ naive。  
4. **Voting**：跨类型相对稳健，API 成本较高。

后期实验的目标不是重复证明 RGB 上的结论，而是回答：

> **在更长上下文、多跳推理、领域专用语料、OCR 记忆图谱等新数据上，上述规律是否成立？哪些方法具有跨数据集泛化性？**

## 2. 相对中期的关键变更

### 2.1 模型配置（生成 vs 判别分离）

### 3.2 统一批量评测入口（后期新增）

`src/smoke_test` 已对接 `_runner` + 自动出图，适合快速得到「方法 × 噪音比例」表和图表：

```bash
python3 -m src.smoke_test \
  --n 50 \
  --dataset bright \
  --language en \
  --subset main \
  --methods naive,prompt,confidence,voting \
  --ratios 0,0.5,0.75
```

产出：

- JSON：`experiments/results/smoke_<dataset>_...json`（含 `robustness_table`）
- 图表：`figures/smoke_<dataset>_.../`（矫正对比、噪音曲线、雷达、ISR-NAR、CRR 等）

## 4. 分实验运行指南

以下默认：**生成 = qwen3-4b（LM Studio）**，**Judge = DeepSeek**。

### 4.1 实验一：噪音影响（扩展数据集）

```bash
# BRIGHT · semantic 梯度
python -m experiments.exp1_noise_impact --n 50 --dataset bright --language en --subset main

# 2Wiki
python -m experiments.exp1_noise_impact --n 50 --dataset 2wiki --language en --subset main

# MobileMem
python -m experiments.exp1_noise_impact --n 50 --dataset mobilemem --language zh --subset calc

# NoiserBench（英文 hotpotqa，七类噪音需配合 noiser 注入逻辑）
python -m experiments.exp1_noise_impact --n 50 --dataset noiser_bench --language en --subset hotpotqa
```

**终期图表**：`figures/*/exp1_noise_impact.png`（naive 基线随 ratio 下降曲线）。

### 4.2 实验二：矫正方法对比

```bash
python -m experiments.exp2_correction --n 50 --dataset bright --language en --subset main \
  --methods naive,prompt,confidence,voting --noise-type semantic

python -m experiments.exp2_correction --n 50 --dataset mobilemem --language zh --subset calc
```

**终期图表**：`exp2_correction.png`（多方法分组柱状图；Judge 为主指标时自动选用 `judge_score`）。

### 4.3 实验三：案例研究

```bash
python -m experiments.exp3_case_study --n 50 --pick 20 \
  --dataset bright --language en --subset main --corrector confidence

python -m experiments.exp3_case_study --n 50 --pick 15 \
  --dataset mobilemem --language zh --subset calc --corrector prompt
```

**终期内容**：案例表格 + Type 分布饼图（对比中期 RGB 案例）。

### 4.4 实验四：互锁效应（方法 × 噪音类型）

```bash
# BRIGHT · semantic vs counterfactual（fact 子集）
python -m experiments.exp4_existing_methods --n 50 --dataset bright --language en --subset main \
  --noise-type semantic --ratio 0.75
python -m experiments.exp4_existing_methods --n 50 --dataset bright --language en --subset fact \
  --noise-type counterfactual --ratio 0.75
```

**终期图表**：`exp4_interlock_heatmap.png`（可与中期 RGB 热力图并列）。

### 4.5 实验五：深化（自适应 / 消融 / iterative_sc）

```bash
python -m experiments.exp5_deep --n 50 --dataset bright --language en
python -m experiments.exp5_deep --n 50 --dataset 2wiki --language en
```

### 4.6 跨数据集噪音梯度

```bash
python -m experiments.exp_noise_gradient --n 50 --datasets rgb,cmedqa,2wiki
python scripts/analyze_noise_gradient.py   # 汇总 Judge 表
```

## 8. 已知问题与注意事项

1. **BRIGHT 规模**：当前 `en.json` 为 **749** 条（已过滤原始 N/A 子域样本）；与中期报告中「1384 条 BRIGHT 原始规模」口径不同，终期需注明。

3. **NoiserBench**：七类预标注噪音与自建 semantic/counterfactual 不同，需单独一节说明。  
4. **MIRIAD 全量禁止**：必须显式 `--n` / `demo_limit`，勿无 limit 加载。  
5. **bash 脚本**：macOS 默认 bash 3.2，请使用已修复的 `scripts/run_three_datasets_n50.sh`（空数组兼容）。
