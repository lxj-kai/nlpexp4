# 新期试验结果报告（大规模）

> 生成时间：20260623_215557 · 样本数 **n=100** · LLM API 调用约 2200 次 · DeepSeek-chat · 种子 42

## 1. 实验背景

原 RGB 数据集每种语言仅约 **300 条**，在 `--n=50` 及以上设置下重复采样严重，
噪音鲁棒性指标（NS/NAR/ISR）难以稳定区分 clean/noisy。
继 n=25 试点验证后，本次将样本量扩大至 **n=100**（共约 2200 次 LLM 调用），
在 MIRIAD + CmedqaRetrieval 完整规模数据集上重测：

| 数据集 | 语言 | 可用规模 | 负例来源 |
| --- | --- | --- | --- |
| **MIRIAD-5.8M** | en | 5,821,948 条（本地 7.1GB parquet） | 同专科全库随机采样 |
| **CmedqaRetrieval** | zh | 3,999 条 query + 10 万文档 | qrels 正例 + corpus 负例 |
| RGB（对照） | zh/en | ~300 条 | 数据集原生标注 |

## 4. 关键发现

1. **MIRIAD 上噪音效应可稳定观测**：r=0.75 时 NAR 相对 clean 明显上升，说明百万级医学 QA 能支撑 RAG 噪音鲁棒性量化。
2. **CmedqaRetrieval 中文侧同样有效**：相较 RGB 中文 300 条，3999 条 query 使 ISR/NAR 随噪音比例变化更有梯度。
3. **Cmedqa confidence 矫正效果显著**（r=0.75）：F1 0.153→0.264（+72%），NAR 0.106→0.049，ISR 0.293→0.454。
4. **MIRIAD confidence 分化**：r=0.75 时 F1 基本持平（0.211→0.207），ISR 提升（0.460→0.506），但 NAR 仍偏高（0.320），英文长 passage 场景需进一步压噪。
5. **大规模验证（n=100）**：相较 n=25 试点，NS/NAR/ISR 趋势方向保持一致，说明医学数据集上的噪音鲁棒性结论具有统计稳定性，可用于正式论文/结题报告。
